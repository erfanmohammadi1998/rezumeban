# رزومه‌بان

سامانهٔ دریافت و مدیریت رزومه برای شرکت‌ها — یک ATS کامل با پورتال عمومی مشاغل و منبع‌یابی کاندیدا.

Built with **Django REST Framework** + **React 19 / Vite / Tailwind v4**.

## امکانات

- **بانک رزومه:** ثبت/ویرایش کاندیدا با سوابق کاری، تحصیلات و مهارت‌ها، آپلود عکس و فایل رزومه، امتیازدهی، برچسب و یادداشت تیمی. جستجو و فیلتر پیشرفته، عملیات گروهی، خروجی CSV، مقایسهٔ کاندیدا.
- **آگهی‌های شغلی:** ساخت/ویرایش آگهی، وضعیت‌ها، انتشار در پورتال عمومی.
- **پورتال عمومی (`/careers`):** صفحهٔ فرصت‌های شغلی و فرم درخواست آنلاین با آپلود رزومه — بدون نیاز به لاگین.
- **پایپ‌لاین استخدام:** برد کانبان کشیدنی برای هر آگهی، رد کردن با دلیل، مراحل قابل تنظیم.
- **مصاحبه‌ها:** زمان‌بندی و ثبت بازخورد ساختاریافته (امتیاز، توصیه، یادداشت).
- **منبع‌یابی:** دریافت آگهی و کاندیدا از منابع واقعی (جاب‌ویژن، ای‌استخدام، Remotive، Greenhouse، GitHub) با جستجوهای ذخیره‌شده.
- **گزارش‌ها:** نرخ استخدام، میانگین زمان تا استخدام، نمودارهای تحلیلی.
- جستجوی سریع (Ctrl/⌘+K)، اعلان‌ها، راهنمای درون‌برنامه‌ای، رابط واکنش‌گرا.

## اجرا

### بک‌اند (Django REST)

```bash
python -m venv venv
venv\Scripts\activate             # ویندوز
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 8010
```

پیکربندی ماژول‌ها با متغیر محیطی `TALENTBASE_MODULES` (پیش‌فرض: `core,recruitment,sourcing`).
مستندات API: `http://127.0.0.1:8010/api/docs/`.

### فرانت‌اند (React + Vite + Tailwind v4)

```bash
cd frontend
npm install
copy .env.example .env            # VITE_API_BASE را تنظیم کنید
npm run dev
```

### تست

```bash
python manage.py test candidates
```

## ساختار

- `backend/` — تنظیمات و مسیرهای پروژهٔ Django
- `candidates/` — مدل‌ها، سریالایزرها، ویوها، منبع‌یابی، تست‌ها
- `frontend/src/features/` — ماژول‌های رابط کاربری (auth, candidates, jobs, pipeline, interviews, reports, sourcing, portal, ...)
